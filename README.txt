CODIFICADOR DE PRESTACIONES MENDOZA - PROTOTIPO ANDROID

Esta carpeta contiene una PWA (aplicación web instalable) de prototipo.
Puede abrirse en Chrome en Android y agregarse a la pantalla de inicio.

IMPORTANTE:
Esta versión NO debe usarse todavía para facturación. Es la interfaz/prototipo.
La lectura automática de PDF, detección de MAYÚSCULA + NEGRITA y generación del
PDF final requieren integrar un motor PDF/OCR y la base completa validada del
Nomenclador Marzo 2026.

Reglas incorporadas:
- GLUCOSA EN SUERO -> GLUCEMIA -> 01.073
- En laboratorios deberá incluirse ACTO BIOQUÍMICO, pero el código debe validarse
  directamente contra la tabla correspondiente del nomenclador antes de producción.

Para instalar como app:
1. Abrir index.html en Chrome (o publicar esta carpeta en un hosting HTTPS).
2. En Chrome: menú ⋮ -> "Agregar a pantalla de inicio" / "Instalar aplicación".
